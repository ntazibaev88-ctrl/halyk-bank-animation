# Астана — болашақтың қаласы

A 136-second vertical (1080×1920, 30 fps) 2D animated documentary about Astana, fully in Kazakh:
narration, burned-in subtitles and on-screen text. Built as a [HyperFrames](https://hyperframes.heygen.com)
project (HTML + GSAP timelines rendered frame by frame to MP4).

Final render: `renders/astana-bolashaqtyn-qalasy.mp4`

## Structure

| Path | What it is |
| --- | --- |
| `index.html` | Root composition: mounts the 8 scenes, the caption track and all audio (generated by `tools/build.py`) |
| `compositions/s1.html … s8.html` | One scene per file (intro, history, architecture, population, economy, tourism, future, finale) |
| `compositions/captions.html` | Kazakh subtitles, timed from the narrator's word clock (generated) |
| `assets/js/astana.js` | Shared illustration + motion library: landmarks (Бәйтерек, Ақорда, Хан Шатыр, EXPO, пирамида, мешіт, опера, музей), skylines, trees, people, construction wipes, counters |
| `assets/js/timing.js` | Word-level voice timings, so visuals land on the spoken word (generated) |
| `assets/audio/` | Voiceover per scene, original score, transition effects |
| `tools/tts.py` | Generates the narration (Microsoft neural voice `kk-KZ-DauletNeural`, male, rate −8 %) with word timings |
| `tools/music.py` | Synthesises the original score from code and pre-ducks it under the voice |
| `tools/build.py` | Assembles `index.html`, captions and the timing file |

## Rebuild

```bash
pip install edge-tts numpy scipy
python3 tools/tts.py "-8%"   # voiceover + word timings (needs network)
python3 tools/build.py        # index.html, captions, timing.js
python3 tools/music.py        # original score
npm run check                 # HyperFrames lint + layout + contrast
npm run render                # renders/astana-bolashaqtyn-qalasy.mp4
```

## Facts and sources

- 1997 — capital moved from Almaty to Aqmola; 1998 — renamed Astana; 2019 — Nur-Sultan; 2022 — Astana restored.
- Population: **1 707 150** on 1 October 2026; **+67 974** since the start of the year
  (Bureau of National Statistics, as reported by Egemen Qazaqstan / Astana TV on 2 Nov 2026).
  Sparkline points: 1 Jan (derived from the reported growth), 1 Jun 1 674 699, 1 Aug 1 690 605, 1 Sep 1 700 385, 1 Oct.
- Investment in fixed capital, Astana, January–August 2026: **1 515,2 bn tenge**, 102,7 % of the same period of 2025
  (Bureau of National Statistics regional page for Astana, published 17 Sep 2026).
- No other statistics are shown; the economy scene otherwise describes sectors without numbers.
