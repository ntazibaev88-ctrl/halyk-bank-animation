# ҚАЗАҚСТАН — 35 ЖЫЛДАҒЫ ДАМУ ЖОЛЫ · 1991–2026

A National-Geographic-style documentary about how Kazakhstan has changed in 35 years.
Vertical 1080×1920 · 30 fps · 120 s · Kazakh narration and subtitles · original Kazakh cinematic score. Built in [HyperFrames](https://hyperframes.heygen.com).

## Edit and re-render
```bash
python3 tools/build_scenes.py                 # regenerate scenes after editing SHOTS
npx hyperframes@0.9.20 check                  # lint + layout + audio checks
npx hyperframes@0.9.20 render -o renders/kz35-journey.mp4
```
- Narration: edit `script/narration.json` → `python3 tools/tts.py` → `python3 tools/build_voice_captions.py` (keep `script/timeline.json` in step).
- Music: `python3 tools/compose_score.py` (numpy, scipy, soundfile).
- New satellite view: `python3 tools/sentinel.py <name> <lat> <lon> <width_km> <height_km> 1080 1920 [2025-08]`.
- 3D clips: see `world3d/` (`node render_clips.mjs 0.8 /tmp/clips`, then encode with ffmpeg).
- Real footage: drop a video into `assets/` and add a `clip` layer in `tools/build_scenes.py`.
