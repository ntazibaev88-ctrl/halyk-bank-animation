# ПТЭ — Правила технической эксплуатации ТЭС (анимационный ролик)

Образовательный 2D-ролик (9:16, 1080×1920, 30 fps, ≈113 c, русский язык) на **Hyperframes** (HTML + GSAP → MP4).

**Результат:** `out/pte_tes_1080x1920.mp4`

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | корневая композиция: 8 сцен, титры, переходы, аудиодорожки (генерируется `tools/build.py`) |
| `compositions/s1…s8.html` | сцены-подкомпозиции (генерируются из `src/scenes/`) |
| `src/scenes/s1…s8.html` | **редактируемые исходники сцен** (SVG + GSAP-таймлайн) |
| `src/shared/` | общий CSS/JS-хелперы (поток, шестерни, манометры, 3D-боксы), персонаж-оператор |
| `src/root.tpl.html` | шаблон корневой композиции (стили субтитров, прогресс-бар, переходы) |
| `voiceover/script.json` | **текст дикторской озвучки** по сценам и предложениям (`SCRIPT.md` — читаемая версия) |
| `voiceover/sentences/*.wav` | озвучка по предложениям |
| `data/timing.json` | рассчитанные тайминги сцен, предложений, субтитров |
| `subtitles/pte.srt`, `pte.vtt` | субтитры отдельными файлами |
| `audio/*.mp3` | дорожки: голос, музыка (ducking под голос), ambience, SFX |
| `tools/` | генераторы: голос, тайминги, аудио, сборка, экспорт субтитров |
| `assets/` | шрифты Inter (кириллица), GSAP |

## Сцены

1. Крючок (0–12.9 c): ночная станция, пролёт по цеху, аварийная сигнализация, «ЧТО БУДЕТ, ЕСЛИ НАРУШИТЬ ПТЭ?»
2. Что такое ПТЭ: документ → схема станции с подсветкой систем
3. Котёл: разрез, горение, нагрев воды, циркуляция, пар, манометры, уровень, защиты
4. Турбина → генератор → электроэнергия
5. Вспомогательное оборудование: насос, арматура, трубопроводы, теплообменник, водоподготовка, дымосос/вентилятор, КИП
6. Безопасность: СИЗ, осмотр, блокировка и бирка (иллюстративно), запреты
7. Оператор: пульт, обход, журнал параметров, реакция на отклонение
8. Финал: станция → город, «ПТЭ — ОСНОВА НАДЁЖНОЙ РАБОТЫ ТЭЦ», персонал на БЩУ

## Пересборка

```bash
npm install
pip install numpy scipy            # для аудио
sudo apt-get install espeak-ng ffmpeg
python3 tools/voice.py             # озвучка (VO_ENGINE=espeak|external)
python3 tools/timing.py            # сцены, субтитры
python3 tools/audio.py             # голос/музыка/ambience/SFX (wav)
for f in voice music ambience sfx; do ffmpeg -y -i audio/$f.wav -b:a 192k audio/$f.mp3; done
python3 tools/build.py             # index.html + compositions/
python3 tools/export_subs.py       # SRT/VTT + SCRIPT.md
npx hyperframes preview            # просмотр
npx hyperframes render -q standard -o out/pte_tes_1080x1920.mp4
```

## Озвучка

**Текущая озвучка ролика — RHVoice, голос «Михаил»** (русский мужской, офлайн-синтез):
`audio/voice.mp3`, исходники вариантов — `voiceover/candidates/` (также есть «Виталий» для сравнения).

- Генерация: `python3 tools/voice_rhvoice.py mikhail` (нужны `apt-get install rhvoice rhvoice-russian`).
- Текст берётся из `voiceover/script.json` без изменений; каждое предложение вписывается в свой прежний слот
  (`voiceover/lengths.json`) и ставится на прежнее время (`data/timing.json`), поэтому сцены, субтитры и музыка
  не меняются. Подгонка темпа ограничена 0,94–1,10; громкость выравнивается до −17 LUFS.
- Применение: `cp voiceover/candidates/mikhail/voice_mikhail.wav audio/voice.wav` →
  `ffmpeg -i audio/voice.wav -b:a 192k audio/voice.mp3` → рендер.
- Финальный MP4 собран так: видеопоток взят без перекодирования из предыдущего рендера, звук — из нового
  рендера Hyperframes с этим голосом (визуал побитово не изменился).

Предыдущая озвучка eSpeak NG (`tools/voice.py`, `voiceover/sentences/`) оставлена как исходник таймингов.

### Свой голос (живой диктор / нейросервис)

1. Озвучьте каждое предложение из `voiceover/script.json` и положите WAV в `voiceover/external/s{сцена}_{номер}.wav`.
2. Чтобы **сохранить текущие тайминги**, подгоните файлы под слоты так же, как это делает `tools/voice_rhvoice.py`
   (функция `build`); либо, если тайминги можно менять, —
   `VO_ENGINE=external python3 tools/voice.py && python3 tools/timing.py && python3 tools/audio.py` и полная пересборка.

## Музыка и звук

Вся музыка и эффекты синтезируются кодом (`tools/audio.py`, без лицензионного материала): тёмный
кинематографический дрон/пульс, нарастание в сцене 1, удар в финале, сирена тревоги, пар, спул турбины,
сигналы пультов, клапаны, ambience цеха. Музыка автоматически «приседает» под голос.

## Техническая точность

Ролик носит общий образовательный характер. В нём нет номеров статей, нормативных пунктов,
рабочих параметров (давлений, температур) и значений уставок. Сцена безопасности (LOTO, СИЗ) —
иллюстрация, не инструкция станции. Точные требования добавляются по действующим нормативным
документам Республики Казахстан и утверждённым инструкциям конкретной станции.
