# 2045: МИР, КОТОРЫЙ ДУМАЕТ ЗА ТЕБЯ

Кинематографичная 2D-анимация (вертикальное видео 9:16, 1080×1920, 30 fps, русский язык, ~112 с)
о повседневной жизни в 2045 году: умный дом, беспилотный транспорт, роботы, медицина, образование,
энергетика, обратная сторона прогресса и финальный клиффхэнгер.

Проект собран на **Hyperframes** (HTML → MP4, детерминированный рендер покадровой перемоткой таймлайна) и **GSAP**.

## Сборка с нуля

```bash
npm install                        # hyperframes, gsap, motion, шрифты (@fontsource)
pip install piper-tts sherpa-onnx numpy
bash tools/fetch_voice_models.sh   # нейро-голос ru_RU-ruslan + распознаватель GigaAM-v2 (~470 МБ, в /opt/tts)
python3 tools/build_voice.py       # озвучка: дубли → проверка распознаванием → тайминги по словам
python3 tools/build_audio.py       # музыка + SFX (numpy), дакинг под голос
python3 tools/build_project.py     # сцены, субтитры, SRT, index.html, voiceover_ru.txt
python3 tools/build_storyboard.py  # storyboard.md с актуальными таймкодами
npx hyperframes check              # lint + runtime + layout + contrast
npx hyperframes render -o final_video.mp4 -q high -f 30
```

Требования: Node ≥ 22, FFmpeg (с soxr), Python 3.

## Как это устроено

* **Сцены** — 9 независимых компонентов `src/scenes/sceneN.html`. `tools/build_project.py` вшивает в каждый общий CSS/JS и
  передаёт в скрипт сцены `D` (длительность), `CH[]`/`CE[]` (начало/конец реплик диктора внутри сцены), поэтому
  анимации привязаны к реальным моментам озвучки. Поменяли текст или темп — пересоберите, и всё сдвинется.
* **Графика** — SVG + HTML/CSS (процедурный город, силуэты, роботы, голографические панели, орбиты планет, лицо-скан, глаз).
  Всё — функция времени: сидированный ГПСЧ, без `Date.now()`/`Math.random()`, без бесконечных повторов.
* **Камера и глубина** — медленные push-in, параллакс слоёв, лёгкий drift частиц, свечения, scanlines, виньетка.
* **Переходы** — световой луч + вспышка + «стрики» на каждой границе сцен (`compositions/fx.html`), сама сцена входит с
  размытием/яркостью и уходит push-through.
* **Субтитры** — `compositions/subs.html`: крупный белый Inter 700, ключевые слова циановые, максимум 2 строки, безопасные поля,
  плавный вход/выход; те же данные формируют `subtitles_ru.srt`.
* **Звук** — `tools/build_audio.py` синтезирует саундтрек и десятки SFX-событий (клики часов, серво, V2X-чирпы, ЭКГ, сварка,
  глитч, сердцебиение, финальные удары) строго по меткам сцен; музыка автоматически «прижимается» sidechain-компрессией под голос.
  Дорожки раздельные (`vo`, `music`, `sfx`) — громкость правится атрибутом `data-volume` в `index.html`.

### Про Motion
Библиотека `motion` установлена и доступна, но Hyperframes рендерит видео перемоткой *seek-able* таймлайнов (GSAP, WAAPI),
а `motion.animate()` живёт на реальных часах и не детерминирован покадрово. Поэтому вся анимация идёт через GSAP-таймлайны
(официальный движок Hyperframes), а не через Motion — это сознательное решение, а не пропуск.

## Озвучка

**Голос:** нейросетевой русский мужской голос Piper VITS `ru_RU-ruslan-medium` (носитель языка, обучен на русской речи; не англоязычная модель).
Выбран из трёх мужских русских голосов слепым тестом: распознаватель речи безошибочно прочитал все ключевые термины только у него,
и у него самый низкий тембр (основной тон ≈114 Гц).

**Как делается озвучка (`tools/build_voice.py`):**
1. **Ударения.** Все ~170 уникальных слов сценария проверены по фонемам. Исправлены ошибки фонемайзера: «со́рок» (не «соро́к»),
   «в … году́» (не «го́ду»). Для чётких окончаний («оконча́тельные решения тре́буют», «заболева́ний») окончания заданы явно на уровне фонем.
2. **Дубли, как в студии.** Каждое предложение синтезируется до 6–18 раз. Каждый дубль расшифровывается обратно русским распознавателем
   GigaAM-v2 — и ещё раз с подмешанным шумом −20 дБ (запас разборчивости «под музыкой»). Выбирается дубль, где **все слова
   распознаны без ошибок в обоих случаях** и темп ближе всего к цели. Итог: 27/27 предложений, WER = 0 (и чисто, и в шуме).
3. **Подача.** Темп задан в слогах/с по сценам: медленно и загадочно в начале, уверенно в середине (~140 слов/мин),
   медленнее и напряжённее в сцене 8, самый медленный — финальный вопрос. Паузы — между предложениями и драматические
   перед ключевыми фразами («…две тысячи сорок пятом году. // Но самое странное —», «…станут машины. // А останемся ли мы…»).
4. **Обработка голоса:** high-pass 70 Гц, тепло +3 дБ@120 Гц, срез «бубнения» −2 дБ@320 Гц, разборчивость +2,5 дБ@3,3 кГц,
   де-эссер, компрессия 3:1, громкость −16 LUFS, лимитер (пик ≤ −1,5 dBFS); каждое предложение выровнено по уровню (разброс 3,4 дБ).
5. **Синхронизация.** Таймкоды каждого слова берутся из распознавания реального аудио → субтитры и все анимации привязаны к
   фактической речи (субтитр появляется за 0–0,1 с до начала слова).

**Микс:** музыка и эффекты автоматически «приседают» под голос (sidechain); голос громче фона на 16–24 дБ в каждой реплике, пики ≤ −1,5 dBFS.
Звуковые удары не ложатся на слова: например, глитч «сбоя» звучит в паузе сразу после «…даст сбой?».

**Контроль готового ролика:** `python3 tools/qc_mix.py final_video.mp4` — распознаёт речь прямо из итогового микса (с музыкой и эффектами)
и сверяет со сценарием по предложениям.

**Замена голоса (профессиональный диктор или другой русский нейро-TTS — ElevenLabs, Yandex SpeechKit, SaluteSpeech и т.п.):**
`voiceover_ru.txt` — готовый к записи сценарий с ударениями, паузами и указаниями к подаче. Запишите его и выполните

```bash
python3 tools/align_voice.py мой_диктор.wav   # распознаёт запись, пословно выравнивает, пересчитывает все тайминги
python3 tools/build_audio.py && python3 tools/build_project.py && python3 tools/build_storyboard.py
npx hyperframes render -o final_video.mp4 -q high -f 30
```

Сцены, субтитры, SFX и музыка подстроятся под новую запись автоматически.

## Отклонения от ТЗ

* **Длительность ~112 с** вместо 90–100 с. Полный исходный текст (204 слова, включая «две тысячи сорок пятом») в требуемом темпе
  125–140 слов/мин с естественными и драматическими паузами физически занимает ~91 с чистой речи + паузы + финальный экран.
  Сократить до 100 с можно только ускорив речь или урезав текст — см. `script/narration.json` (поля `pace`, `gap`).
* Текст озвучки — **дословно по ТЗ**. Единственное изменение — «2045» читается словами.
* Голос — лучший доступный офлайн нейро-голос; «эфирное» качество живого диктора достигается заменой записи (см. выше).
