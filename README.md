# АСТАНА 1997–2026: ЕЛОРДАНЫҢ ӨЗГЕРУ ЖОЛЫ

Астананың 1997–2026 жылдардағы тарихы туралы 110 секундтық вертикал анимациялық деректі ролик
(9:16, 1080×1920, 30 fps). Дикторлық мәтін, субтитрлер, тақырыптар мен инфографика — қазақ тілінде.

**Дайын видео:** `out/astana_1997_2026_kk.mp4` · **Субтитрлер:** `out/subtitles_kk.srt` (кадрға енгізілген және бөлек жолақ ретінде қосылған)

| Уақыт | Бөлім |
|---|---|
| 0–7 с | Заманауи Астана, тақырып |
| 7–18 с | 1997 — елорда Ақмолаға көшті; 1998 — Астана атауы |
| 18–40 с | Бәйтерек (2002), Ақорда (2004), Бейбітшілік және келісім сарайы (2006), Хан Шатыр (2010), Әзірет Сұлтан мешіті (2012) |
| 40–53 с | ЭКСПО-2017 және «Нұр Әлем» |

| 99–110 с | Хронология және қорытынды |

## Құрылымы

- `narration/script_kk.json` — дикторлық мәтін (бөлімдер мен уақыт терезелері; `sub` — субтитр, `tts` — дыбыстау үшін сандар сөзбен).
- `tools/build_audio_kk.py` — нейрондық қазақ дауысы `kk-KZ-DauletNeural` (edge-tts), әр бөлімді өз терезесіне сыйғызу, субтитрлерді сөз деңгейіндегі уақыт белгілері бойынша синхрондау.
- `tools/music.py`, `tools/mix_audio.sh` — музыка, ducking, −14 LUFS мастеринг.
- `web/landmarks.js`, `web/scenes.js` — векторлық иллюстрациялар және сахналар.
- `tools/render_video.sh` — headless Chromium арқылы кадрларды рендерлеу.

Толық жинау: `./build.sh`. Субтитрлер мен хронология жолағы TikTok интерфейсінің төменгі аймағынан жоғары орналастырылған.
