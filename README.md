# АСТАНА 1997–2026: ЕЛОРДАНЫҢ ӨЗГЕРУ ЖОЛЫ

Астананың 1997–2026 жылдардағы тарихы туралы ≈2 минуттық (139 с) вертикал анимациялық деректі фильм
(9:16, 1080×1920, 30 fps). Дикторлық мәтін, субтитрлер, тақырыптар мен инфографика — қазақ тілінде.
Фильм **HyperFrames** композициясы ретінде жиналып, HyperFrames CLI арқылы рендерленеді (`hyperframes/`).

**Дайын видео:** `out/astana_1997_2026_kk.mp4` · **Субтитрлер:** `out/subtitles_kk.srt`

Сахналар: заманауи Астана → 1997 (карта) → 1998 → Бәйтерек → Ақорда → Бейбітшілік және келісім сарайы → Хан Шатыр →
Әзірет Сұлтан мешіті → EXPO-2017 және Нұр Әлем → 2019 Нұр-Сұлтан, Абу-Даби Плаза → 2022 Астана, Бас мешіт →
халық саны (326 мың → 1 262 000 → 1 700 385) → Tarlan Astana LRT (≈22,4 км, 18 бекет, жүргізушісіз, әуежай — «Нұрлы жол») → қорытынды.
Нақты уақыттар `build/timeline.json` ішінде (дикторлық мәтін ұзақтығы бойынша есептеледі).

## Құрылымы

- `narration/script_kk.json` — дикторлық мәтін (бөлімдер мен уақыт терезелері; `sub` — субтитр, `tts` — дыбыстау үшін сандар сөзбен).
- `tools/build_audio_kk.py` — нейрондық қазақ дауысы `kk-KZ-DauletNeural` (edge-tts), әр бөлімді өз терезесіне сыйғызу, субтитрлерді сөз деңгейіндегі уақыт белгілері бойынша синхрондау.
- `tools/music.py`, `tools/mix_audio.sh` — музыка, ducking, −14 LUFS мастеринг.
- `web/landmarks.js`, `web/scenes.js` — векторлық иллюстрациялар және сахналар.
- `tools/make_hyperframes.sh` — HyperFrames композициясын жинау (`hyperframes/index.html`, GSAP уақыт сызығы кадрды `render(t)` арқылы салады); `tools/render_video.sh` — HyperFrames-сіз балама рендер.

Толық жинау: `./build.sh`. Барлық мәтін TikTok-тың қауіпсіз аймағында (168–1330 px, оң жақ батырмалардан тыс).
